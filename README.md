# C Calculator

Console calculator in C by Harsh Verma.

## Features
- Add, subtract, multiply, divide
- Modulus for integers, power (a^n)
- Input validation, divide-by-zero guard
- Menu loop, clean functions

## Build
```bash
gcc calculator.c -o calculator
```

## Run
```bash
./calculator
# Windows
calculator.exe
```

## Example
```
==== C Calculator ====
1. Add
2. Subtract
3. Multiply
4. Divide
5. Modulus (integers)
6. Power (a^n, n >= 0)
7. Exit
Enter choice (1-7): 1
Enter first number: 12
Enter second number: 8
Result: 20.00
```
